# Network Repair Tool

## 🇬🇧 English

### 📌 What is this program?

Network Repair Tool is a Windows utility designed to automatically diagnose and restore network functionality when users experience internet connection problems, instability, or DNS/network configuration errors.

### ⚠️ Administrator Rights Required
The program must be run **as an administrator**.  
Network reset and recovery operations require elevated privileges to modify system network components and configuration. Without administrator rights, the program cannot perform its functions correctly, and some operations will fail.

### ⚙️ What does it do?

The program performs a sequence of system-level network recovery operations, including:
- Resetting network communication components
- Restoring system network configuration to a clean state
- Clearing corrupted or outdated network cache data
- Reinitializing network parameters for stable connectivity

After completing all operations, the tool notifies the user and prepares the system for a restart to apply all changes correctly.

### 💡 Why was it created?

Network issues in Windows often require multiple technical steps that are difficult and inconvenient for regular users.  
This tool simplifies the entire process into a single automated action, reducing time spent on troubleshooting and eliminating user errors during manual recovery.

### 🚀 Features
- One-click network recovery process
- Fully automated execution
- No manual command-line usage required
- Clear user notifications during execution
- Automatic system restart preparation
- Lightweight and fast execution

## 🇷🇺 Русский

### 📌 Что это за программа?

Network Repair Tool — это утилита для Windows, предназначенная для автоматической диагностики и восстановления работы сети при проблемах с интернет-соединением, нестабильной работой сети или ошибках сетевых настроек.

### ⚠️ Требуются права администратора
Программа должна запускаться **от имени администратора**.  
Для сброса сетевых компонентов и изменения системных сетевых настроек требуются повышенные права.  
Без прав администратора некоторые операции не смогут выполниться, и утилита не сможет корректно восстановить сеть.

### ⚙️ Что делает программа?

Программа выполняет последовательность операций восстановления сети на уровне системы:
- Сбрасывает сетевые компоненты Windows
- Восстанавливает сетевые настройки системы в исходное состояние
- Очищает повреждённые или устаревшие сетевые данные
- Перезапускает параметры сети для стабильной работы

После завершения всех операций программа уведомляет пользователя и подготавливает систему к перезагрузке для применения изменений.

### 💡 Зачем она нужна?

Проблемы с сетью в Windows часто требуют множества сложных действий, которые неудобны для обычного пользователя.  
Данная утилита упрощает процесс до одного запуска, экономя время и снижая вероятность ошибок.

### 🚀 Возможности
- Полная автоматизация восстановления сети
- Работа в один клик
- Не требует ручного использования командной строки
- Уведомления о ходе выполнения
- Автоматическая подготовка к перезагрузке системы
- Лёгкая и быстрая работа

## 🇺🇦 Українська

### 📌 Що це за програма?

Network Repair Tool — це утиліта для Windows, призначена для автоматичної діагностики та відновлення роботи мережі при проблемах з інтернет-з'єднанням, нестабільною роботою мережі або помилках у мережевих налаштуваннях.

### ⚠️ Права адміністратора

Програму потрібно запускати **від імені адміністратора**.  
Для скидання мережевих компонентів та зміни системних мережевих налаштувань потрібні підвищені права.  
Без прав адміністратора деякі операції не зможуть виконатися, і утиліта не зможе коректно відновити мережу.

### ⚙️ Що робить програма?

Програма виконує послідовність системних операцій відновлення мережі:
- Скидає мережеві компоненти Windows
- Відновлює мережеві налаштування системи до початкового стану
- Очищає пошкоджені або застарілі мережеві дані
- Перезапускає параметри мережі для стабільної роботи

Після завершення всіх операцій програма сповіщає користувача та готує систему до перезавантаження для застосування змін.

### 💡 Навіщо вона потрібна?

Проблеми з мережею у Windows часто потребують складних ручних дій, які незручні для звичайного користувача.  
Ця утиліта спрощує процес до одного запуску, економить час і зменшує ризик помилок.

### 🚀 Можливості
- Повна автоматизація відновлення мережі
- Робота в один клік
- Не потребує ручного використання командного рядка
- Сповіщення про хід виконання
- Автоматична підготовка до перезавантаження системи
- Легка та швидка робота
